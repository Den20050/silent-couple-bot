# Проверка: запущен ли бот на другом ПК?

## Текущий статус

✅ **Webhook НЕ установлен** - это означает:
- Бот может работать в polling режиме локально
- Если бот запущен на другом ПК в polling - будет конфликт

## Как проверить, запущен ли бот на другом ПК?

### Способ 1: Проверка через Telegram API (рекомендуется)

Запустите скрипт:
```powershell
python scripts/check_bot_running_elsewhere.py
```

Он покажет:
- ✅ Статус webhook
- ✅ Информацию о боте
- ✅ Рекомендации

### Способ 2: Попробовать запустить локально

Если при запуске появляется ошибка:
```
TelegramConflictError: Conflict: terminated by other getUpdates request
```

Это означает, что бот уже запущен где-то еще (на другом ПК или сервере).

### Способ 3: Проверить на сервере

Если бот должен работать на сервере:

```bash
ssh root@91.222.237.94
sudo systemctl status silent-couple-bot-webhook
```

Если сервис запущен - бот работает на сервере через webhook.

## Что делать дальше?

### Вариант А: Бот должен работать на сервере

1. **Установите webhook:**
   ```powershell
   # Укажите WEBHOOK_URL в .env
   # WEBHOOK_URL=https://24policybot.ru/webhook/telegram
   
   # Установите webhook
   python scripts/set_webhook.py
   ```

2. **Проверьте на сервере:**
   ```bash
   ssh root@91.222.237.94
   sudo systemctl status silent-couple-bot-webhook
   ```

3. **НЕ запускайте бот локально** - используйте только webhook на сервере

### Вариант Б: Бот должен работать локально

1. **Проверьте все ПК** - убедитесь, что бот не запущен на других компьютерах

2. **Убедитесь, что webhook не установлен:**
   ```powershell
   python scripts/check_webhook_status.py
   ```

3. **Если webhook установлен - удалите его:**
   ```powershell
   python scripts/set_webhook.py delete
   ```

4. **Запустите бот локально:**
   ```powershell
   python run.py
   ```

## Рекомендации

### Если бот запущен на другом ПК в polling режиме:

**Проблема:** Конфликт при попытке запустить локально

**Решение:**
1. Остановите бот на другом ПК
2. Или установите webhook и запустите бот на сервере
3. Или договоритесь, кто где работает (один ПК = один экземпляр)

### Если бот должен работать на сервере:

**Рекомендуется:**
1. Установить webhook
2. Запустить бот на сервере через systemd
3. НЕ запускать локально в polling режиме

### Если бот должен работать локально:

**Рекомендуется:**
1. Убедиться, что webhook не установлен
2. Убедиться, что бот не запущен на других ПК
3. Запускать только один экземпляр локально

## Полезные скрипты

- `scripts/check_bot_running_elsewhere.py` - проверка статуса бота
- `scripts/check_webhook_status.py` - проверка webhook статуса
- `scripts/set_webhook.py` - установка/удаление webhook
- `scripts/restore_webhook_if_needed.py` - восстановление webhook при необходимости
