# Решения проблемы с конвертацией валют при оплате через Robokassa

## Проблема

При оплате подписки в валюте через Robokassa возникает несоответствие:
- В `.env` захардкожены цены в разных валютах (USD, EUR, UAH и т.д.)
- Robokassa конвертирует валюту в рубли по текущему курсу на момент оплаты
- Из-за колебаний курса захардкоженная цена может не совпадать с реальной стоимостью

**Пример:**
- Захардкожено: USD 2.99
- Курс USD/RUB на момент оплаты: 100 руб/доллар
- Robokassa получит: 2.99 USD = 299 руб
- Но если курс изменился до 95 руб/доллар, то 2.99 USD = 284 руб (меньше ожидаемой цены в рублях)

---

## Варианты решения

### Вариант 1: Хранить только RUB, конвертировать динамически при показе ⭐ РЕКОМЕНДУЕТСЯ

**Суть:** Хранить цены только в рублях, использовать API курсов валют для расчета примерной цены в выбранной валюте при показе тарифов.

**Плюсы:**
- ✅ Одна базовая валюта (RUB) — проще поддерживать
- ✅ Точность: цена всегда соответствует реальной стоимости
- ✅ Автоматическая адаптация к курсу
- ✅ Прозрачность для пользователя

**Минусы:**
- ⚠️ Нужен API курсов валют (бесплатные варианты доступны)
- ⚠️ Цена может немного меняться между показом и оплатой (но это нормально)

**Реализация:**
1. Убрать все валюты кроме RUB из `SUBSCRIPTION_PRICES`
2. Добавить сервис для получения курсов валют (exchangerate-api.com, ЦБ РФ API, или fixer.io)
3. При показе тарифов конвертировать цену в RUB в выбранную валюту по текущему курсу
4. При создании платежа отправлять сумму в выбранной валюте (Robokassa конвертирует в RUB)

**API для курсов валют:**
- **Exchangerate-API** (бесплатно до 1500 запросов/месяц): https://www.exchangerate-api.com/
- **ЦБ РФ API** (бесплатно): https://www.cbr.ru/development/sxml/
- **Fixer.io** (бесплатно до 100 запросов/месяц): https://fixer.io/
- **Open Exchange Rates** (бесплатно до 1000 запросов/месяц): https://openexchangerates.org/

---

### Вариант 2: Динамический пересчет при создании платежа

**Суть:** При создании платежной ссылки получать текущий курс и пересчитывать цену.

**Плюсы:**
- ✅ Точная цена на момент оплаты
- ✅ Нет расхождений между показанной и реальной ценой

**Минусы:**
- ⚠️ Цена может отличаться от той, что показана пользователю при выборе тарифа
- ⚠️ Нужен API курсов валют
- ⚠️ Сложнее UX (пользователь видит одну цену, платит другую)

**Реализация:**
1. При показе тарифов использовать захардкоженные цены (как сейчас)
2. При создании платежа получать текущий курс
3. Пересчитывать цену из RUB в выбранную валюту
4. Отправлять пересчитанную сумму в Robokassa

---

### Вариант 3: Принимать оплату только в RUB

**Суть:** Убрать поддержку других валют, принимать оплату только в рублях.

**Плюсы:**
- ✅ Простота реализации
- ✅ Нет проблем с курсом
- ✅ Robokassa автоматически конвертирует с карт других валют

**Минусы:**
- ❌ Пользователи видят цену в рублях (даже если у них другая валюта)
- ❌ Менее удобно для международных пользователей

**Реализация:**
1. Убрать выбор валюты из UI
2. Всегда использовать RUB при создании платежа
3. Robokassa автоматически конвертирует с карт других валют

---

### Вариант 4: Хранить цены в валютах с запасом (маржа)

**Суть:** Увеличить цены в валютах с учетом возможных колебаний курса (например, +10-15% запас).

**Плюсы:**
- ✅ Простота (не нужен API)
- ✅ Покрывает колебания курса

**Минусы:**
- ❌ Пользователи могут переплачивать
- ❌ Нужно регулярно пересматривать маржу
- ❌ Не решает проблему полностью (курс может сильно измениться)

**Реализация:**
1. Увеличить все цены в валютах на 10-15%
2. Регулярно проверять и корректировать цены

---

### Вариант 5: Фиксированный курс для конвертации

**Суть:** Установить фиксированный курс для каждой валюты и пересчитывать цены на его основе.

**Плюсы:**
- ✅ Предсказуемость
- ✅ Не нужен API (можно обновлять вручную)

**Минусы:**
- ❌ Нужно регулярно обновлять курсы
- ❌ Возможны расхождения с реальным курсом
- ❌ Риск потерь при сильных колебаниях

**Реализация:**
1. Добавить настройку фиксированных курсов в `.env`
2. При показе тарифов конвертировать RUB → валюта по фиксированному курсу
3. Регулярно обновлять курсы вручную

---

## Рекомендация

**Рекомендуется Вариант 1** — хранить только RUB, конвертировать динамически при показе.

**Причины:**
1. Точность и соответствие реальной стоимости
2. Автоматическая адаптация к курсу
3. Простота поддержки (одна базовая валюта)
4. Прозрачность для пользователя

**Альтернатива:** Если нет возможности использовать API курсов, можно использовать **Вариант 3** (только RUB) — Robokassa автоматически конвертирует с карт других валют.
