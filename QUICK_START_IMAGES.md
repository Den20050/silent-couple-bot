# Быстрый старт: Загрузка картинок

## Минимальная инструкция (3 шага)

### 1. Получите ваш Telegram chat_id

Откройте Telegram → найдите `@userinfobot` → отправьте сообщение → скопируйте ваш `id`

**Или** начните диалог с вашим ботом командой `/start` (бот должен быть запущен)

### 2. Убедитесь, что бот может вам писать

Найдите вашего бота в Telegram → нажмите "Начать" → убедитесь, что бот отвечает

### 3. Запустите загрузку

```bash
python scripts/load_images.py <ваш_chat_id>

# Пример:
python scripts/load_images.py 123456789
```

## Что будет происходить

- Скрипт отправит все картинки боту (они появятся в вашем Saved Messages)
- Каждые 10 картинок вы увидите прогресс
- После завершения все `file_id` будут сохранены в БД
- **Время**: ~15-30 минут для ~1700 картинок

## После загрузки

Проверьте результат:
```bash
python scripts/check_tables.py
```

Должно показать `pics_pool` с ~1749 строками.

## Готово! 🎉

Теперь можно запускать бота - картинки будут отправляться быстро.
