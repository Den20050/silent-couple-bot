# Когда нужно сбрасывать daily_state при изменении времени в .env?

## Короткий ответ

**НЕТ, сброс нужен не всегда!**

Сброс нужен **только если**:
- ✅ Картинка **уже была отправлена сегодня**
- ✅ И вы хотите протестировать отправку **снова в этот же день**

## Подробное объяснение

### Сценарий 1: Картинка еще НЕ отправлялась сегодня

**Что делать:**
1. Измените время в `.env`
2. Перезапустите бота (`Ctrl+C`, затем `python run.py`)
3. **Сброс НЕ нужен** - картинка отправится в новое время

**Пример:**
- Текущее время: `10:00` (13 декабря)
- Картинка еще не отправлялась сегодня
- Вы изменяете `.env`: `MORNING_START=10:05`
- Перезапускаете бота
- ✅ В 10:05 картинка отправится (сброс не нужен)

### Сценарий 2: Картинка УЖЕ отправлялась сегодня

**Что делать:**
1. Измените время в `.env`
2. **Сбросьте daily_state:** `python scripts/reset_daily_state.py <pair_id> both`
3. Перезапустите бота (`Ctrl+C`, затем `python run.py`)
4. Картинка отправится в новое время

**Пример:**
- Картинка была отправлена в `16:00` (13 декабря)
- Текущее время: `20:00` (13 декабря)
- Вы изменяете `.env`: `MORNING_START=20:05`
- ❌ Без сброса: картинка НЕ отправится (уже отправлена сегодня)
- ✅ Со сбросом: `python scripts/reset_daily_state.py 4 both`, затем перезапуск - картинка отправится в 20:05

### Сценарий 3: Следующий день

**Что делать:**
1. Измените время в `.env`
2. Перезапустите бота
3. **Сброс НЕ нужен** - на следующий день `date.today()` изменится, и картинка отправится в новое время

**Пример:**
- Картинка была отправлена `13 декабря в 16:00`
- Вы изменяете `.env`: `MORNING_START=21:20`
- Перезапускаете бота
- ✅ **14 декабря** в 21:20 картинка отправится (сброс не нужен, так как это уже другой день)

## Алгоритм принятия решения

```
Изменили время в .env?
│
├─ Картинка уже отправлялась сегодня?
│  │
│  ├─ ДА → Нужно протестировать снова сегодня?
│  │  │
│  │  ├─ ДА → Запустите: python scripts/reset_daily_state.py <pair_id> both
│  │  └─ НЕТ → Просто перезапустите бота, картинка отправится завтра
│  │
│  └─ НЕТ → Просто перезапустите бота, картинка отправится в новое время
│
└─ Перезапустите бота: Ctrl+C, затем python run.py
```

## Практические рекомендации

### Для быстрого тестирования (в один день)

1. **Проверьте, отправлялась ли картинка сегодня:**
   ```powershell
   # Запустите скрипт проверки (если есть)
   # Или проверьте логи на наличие "Morning message already sent today"
   ```

2. **Если отправлялась - сбросьте:**
   ```powershell
   python scripts/reset_daily_state.py 4 both
   ```

3. **Измените время в .env** (на текущее + 2-3 минуты)

4. **Перезапустите бота:**
   ```powershell
   # Ctrl+C в терминале с ботом
   python run.py
   ```

5. **Подождите до установленного времени**

### Для обычного использования (не тестирование)

1. **Измените время в .env**

2. **Перезапустите бота:**
   ```powershell
   # Ctrl+C в терминале с ботом
   python run.py
   ```

3. **Картинка отправится:**
   - В новое время, если еще не отправлялась сегодня
   - Завтра в новое время, если уже отправлялась сегодня

## Резюме

| Ситуация | Нужен сброс? | Что делать |
|----------|--------------|------------|
| Картинка еще не отправлялась сегодня | ❌ НЕТ | Изменить .env → Перезапустить бота |
| Картинка уже отправлялась сегодня, хотите протестировать снова | ✅ ДА | Сбросить → Изменить .env → Перезапустить бота |
| Картинка уже отправлялась сегодня, можно подождать до завтра | ❌ НЕТ | Изменить .env → Перезапустить бота → Ждать завтра |

**Главное правило:** Сброс нужен **только для тестирования несколько раз в один день**. В обычной работе сброс не нужен - картинка отправится завтра в новое время автоматически.
