# 🚀 Быстрый старт для локальной разработки

## ✅ Текущий статус

- ✅ Webhook удален (не мешает polling)
- ✅ Конфликта нет (можно запускать локально)
- ✅ SSH туннели настроены автоматически

## Запуск бота

Просто запустите:

```powershell
python run.py
```

## Что происходит при запуске

1. ✅ Автоматически создаются SSH туннели для Redis и PostgreSQL
2. ✅ Запускается бот в polling режиме
3. ✅ Запускается worker (cron задачи) в отдельном процессе
4. ✅ Бот готов отвечать на команды в Telegram

## Проверка работы

1. Откройте Telegram
2. Найдите бота: @tish_ob_bot
3. Отправьте `/start`
4. Бот должен ответить ✅

## Остановка

Нажмите `Ctrl+C` в терминале - все процессы остановятся корректно.

## Если что-то пошло не так

### Конфликт экземпляров

Если появилась ошибка `TelegramConflictError`:

```powershell
# Остановить все процессы
taskkill /f /im python.exe

# Или используйте скрипт
.\scripts\stop_all_bots.ps1

# Проверить webhook (должен быть удален)
python scripts/check_webhook_status.py
```

### Проверка статуса

```powershell
# Проверить, запущен ли бот где-то еще
python scripts/check_bot_running_elsewhere.py

# Проверить конфликт
python scripts/test_bot_conflict.py
```

## Важно помнить

- ✅ **Локально:** Используйте polling (`python run.py`)
- ✅ **Webhook удален** - не мешает локальной разработке
- ❌ **НЕ запускайте** бот на сервере одновременно с локальным
