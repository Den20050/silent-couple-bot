# Инструкция по полной перезагрузке картинок

## Ситуация

Вы добавили новые уникальные картинки в папки:
- **morning**: 903 картинки
- **evening**: 923 картинки

Все картинки проверены на уникальность (побайтово), дубликатов нет.

## Процесс перезагрузки

### Шаг 1: Очистка БД от старых file_id

```bash
python scripts/clear_images.py
```

Скрипт покажет:
- Сколько картинок будет удалено (утренних и вечерних)
- Попросит подтверждение (введите `yes`)

**Важно:** Это удалит ВСЕ file_id из БД. После этого нужно будет загрузить картинки заново.

### Шаг 2: Загрузка всех картинок заново

```bash
python scripts/load_images.py <your_chat_id>
```

**Что произойдет:**
- Скрипт загрузит все 903 утренних картинок
- Скрипт загрузит все 923 вечерних картинок
- Всего: 1826 картинок
- Время загрузки: примерно 2.5-3 часа (при задержке 5 секунд между загрузками)

**Прогресс:**
- Показывается каждые 10 загруженных картинок
- Показывается каждые 50 обработанных файлов

### Шаг 3: Проверка результата

После завершения загрузки:

```bash
python scripts/check_images_count.py
```

Должно показать:
- Утренних: 903
- Вечерних: 923
- Всего: 1826

## Важные замечания

- ⚠️ **Задержка между загрузками: 5 секунд** - это необходимо для безопасности
- ⚠️ **Скрипт автоматически увеличивает задержку** при обнаружении ограничений Telegram API
- ⚠️ **Если скрипт прервется** - можно запустить снова, он пропустит уже загруженные картинки
- ⚠️ **Картинки будут появляться в вашем Saved Messages** - их можно удалить после загрузки

## Время выполнения

- **Скорость**: ~0.2 картинки в секунду (5 секунд задержка)
- **1826 картинок**: примерно 2.5-3 часа
- **Прогресс**: показывается каждые 10 картинок

## Полный процесс

```bash
# 1. Очистить БД
python scripts/clear_images.py
# Введите: yes

# 2. Загрузить все картинки заново
python scripts/load_images.py <your_chat_id>

# 3. Дождаться завершения (~2.5-3 часа)
# Вы увидите прогресс каждые 10 картинок

# 4. Проверить результат
python scripts/check_images_count.py
```
