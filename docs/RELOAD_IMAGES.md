# Инструкция по перезагрузке картинок после смены токена бота

## Проблема

Если картинки были загружены с другого бота (с другим токеном), их `file_id` не будут работать с новым ботом. 
Telegram `file_id` специфичны для каждого бота и не могут быть использованы другим ботом.

## Решение

### Шаг 1: Очистка старых file_id из базы данных

Перед загрузкой новых картинок нужно очистить старые `file_id` из базы данных:

```bash
# Очистить все старые file_id
python scripts/clear_images.py
```

Скрипт покажет количество записей и попросит подтверждение. Введите `yes` для подтверждения.

### Шаг 2: Получите ваш Telegram chat_id

Вам нужно узнать ваш Telegram chat_id для загрузки картинок:

**Самый простой способ:**
1. Откройте Telegram
2. Найдите бота `@userinfobot`
3. Отправьте ему любое сообщение
4. Бот ответит с вашим `id` (например: `123456789`)

### Шаг 3: Убедитесь, что новый бот может отправлять вам сообщения

1. Найдите вашего бота в Telegram (с новым токеном)
2. Нажмите "Начать" или отправьте `/start`
3. Убедитесь, что бот может вам писать

### Шаг 4: Загрузите картинки заново

```bash
# Замените <your_telegram_chat_id> на ваш реальный ID
python scripts/load_images.py <your_telegram_chat_id>

# Пример:
python scripts/load_images.py 123456789
```

**Что изменилось в скрипте загрузки:**
- ✅ Увеличена базовая задержка с 3 до 5 секунд между загрузками
- ✅ Автоматическое увеличение задержки при обнаружении ограничений Telegram
- ✅ Максимальная задержка до 15 секунд при частых ограничениях
- ✅ Улучшенная обработка ошибок и информативные сообщения
- ✅ **Упрощена логика**: все картинки (утренние и вечерние) загружаются через **основного бота** (`TG_BOT_TOKEN`)

**Важно о выборе бота для загрузки:**
- **Все картинки** (утренние и вечерние) загружаются через **основного бота** (`TG_BOT_TOKEN`)
- Это гарантирует, что `file_id` будут работать корректно, так как тот же бот используется для отправки картинок пользователям

### Шаг 5: Проверка результата

После завершения загрузки проверьте результат:

```bash
# Проверьте количество загруженных картинок
python scripts/check_images_count.py
```

Должно показать:
- Утренних: ~944 файлов
- Вечерних: ~645 файлов
- Всего: ~1589 файлов

## Время выполнения

- **Задержка**: 5 секунд между загрузками (для безопасности)
- **Скорость**: ~0.2 картинки в секунду
- **Общее время**: ~40-60 минут для ~1600 картинок
- **Прогресс**: Показывается каждые 10 картинок

## Что происходит во время загрузки

1. Скрипт отправляет каждую картинку боту (она появится в вашем Saved Messages)
2. Получает `file_id` от Telegram
3. Сохраняет `file_id` в базу данных
4. Делает паузу 5 секунд перед следующей картинкой
5. При обнаружении ограничений автоматически увеличивает задержку

## Если скрипт прервался

Если скрипт остановился (ошибка, прерывание):

1. **Не переживайте** - уже загруженные картинки сохранены в БД
2. **Запустите скрипт снова** - он пропустит уже загруженные картинки
3. **Продолжит с места остановки** - загрузит только оставшиеся

## После загрузки

После успешной загрузки:

1. ✅ Все `file_id` сохранены в БД с новым токеном бота
2. ✅ Бот может быстро отправлять картинки пользователям
3. ✅ Можно удалить сообщения из Saved Messages (опционально)
4. ✅ Можно запускать бота и тестировать

### Проверка пропущенных картинок

Если скрипт загрузки пропустил некоторые картинки (пометил их как дубликаты), вы можете проверить и догрузить их:

**Шаг 1: Анализ пропущенных картинок (без загрузки)**

```bash
# Проанализировать пропущенные картинки
python scripts/analyze_skipped.py
```

Этот скрипт покажет:
- Сколько картинок было пропущено
- Причины пропуска
- Сколько из них реальные дубликаты (file_id уже в БД)
- Сколько нужно загрузить заново

**Шаг 2: Дозагрузка пропущенных картинок**

```bash
# Проверьте и догрузите пропущенные картинки
python scripts/reload_skipped_images.py <your_chat_id>
```

**Что делает скрипт `reload_skipped_images.py`:**
- Читает список пропущенных файлов из `image/skipped_morning_morning.txt` и `image/skipped_evening_evening.txt`
- Проверяет каждый файл - действительно ли это дубликат
- Если файл не является дубликатом - загружает его заново
- Если файл является дубликатом - пропускает его

**Важно:**
- Скрипт `load_images.py` автоматически создает файлы со списком пропущенных картинок при загрузке
- Если файлы не найдены, скрипты сообщат об этом
- Скрипт использует ту же задержку (5 секунд) для безопасности

## Пример полного процесса

```bash
# 1. Очистить старые file_id
python scripts/clear_images.py
# Введите: yes

# 2. Получите chat_id (через @userinfobot)
# Ваш ID: 123456789

# 3. Начните диалог с ботом в Telegram
# Отправьте /start новому боту

# 4. Загрузите картинки заново
python scripts/load_images.py 123456789

# 5. Дождитесь завершения (~40-60 минут)
# Вы увидите прогресс каждые 10 картинок

# 6. Проверьте результат
python scripts/check_images_count.py
```

## Важные замечания

- ⚠️ **Не запускайте бота во время загрузки картинок** - это может вызвать конфликты
- ⚠️ **Убедитесь, что токен бота в `.env` файле обновлен** перед запуском скрипта очистки
- ⚠️ **Задержка между загрузками увеличена до 5 секунд** для безопасности
- ⚠️ **Скрипт автоматически увеличивает задержку** при обнаружении ограничений Telegram API
- ⚠️ **Все картинки загружаются через основного бота** (`TG_BOT_TOKEN`) - это гарантирует корректную работу `file_id` при отправке пользователям
