# Как использовать скрипты для проверки настроек времени

## Скрипт: `scripts/check_time_settings.py`

### Назначение
Скрипт проверяет:
- Текущие настройки времени из файла `.env`
- Загруженные константы времени в `src/core/constants.py`
- Соответствие между ними
- Дает рекомендации для тестирования

### Как правильно запустить

**В PowerShell:**
```powershell
python scripts/check_time_settings.py
```

**В командной строке (CMD):**
```cmd
python scripts\check_time_settings.py
```

**Важно:** 
- ❌ НЕ запускайте как `scripts/check_time_settings.py` напрямую
- ✅ Всегда используйте `python` перед путем к скрипту

### Что показывает скрипт

1. **Текущее время:**
   - UTC время
   - Локальное время

2. **Настройки из .env:**
   - `MORNING_START`
   - `MORNING_END`
   - `EVENING_START`
   - `EVENING_END`

3. **Загруженные константы:**
   - `MORNING_WINDOW_START`
   - `MORNING_WINDOW_END`
   - `EVENING_WINDOW_START`
   - `EVENING_WINDOW_END`

4. **Проверка соответствия:**
   - ✅ Совпадает - настройки загружены правильно
   - ❌ НЕ СОВПАДАЕТ - нужно перезапустить бота

5. **Рекомендации для тестирования:**
   - Предлагает время для теста (текущее + 2 минуты)
   - Инструкции по изменению `.env` и перезапуску бота

### Если скрипт не выводит результат

**Возможные причины:**
1. Проблема с кодировкой в PowerShell
2. Ошибка импорта модулей
3. Проблема с выводом в консоль

**Решение:**
1. Попробуйте запустить в обычной командной строке (CMD):
   ```cmd
   cd C:\Silent-Couple-Bot
   python scripts\check_time_settings.py
   ```

2. Или сохраните вывод в файл:
   ```powershell
   python scripts/check_time_settings.py > result.txt
   type result.txt
   ```

3. Проверьте, что Python установлен:
   ```powershell
   python --version
   ```

4. Проверьте, что вы в правильной директории:
   ```powershell
   cd C:\Silent-Couple-Bot
   pwd
   ```

## Скрипты проверки базы данных

### Скрипт: `scripts/check_db.py`

**Назначение:**
Проверяет подключение к базе данных PostgreSQL с автоматическим созданием SSH туннеля при необходимости.

**Запуск:**
```powershell
python scripts/check_db.py
```

**Что делает:**
- Автоматически создает SSH туннель, если `DATABASE_SSH_HOST` настроен в `.env`
- Проверяет подключение к PostgreSQL
- Показывает версию PostgreSQL
- Проверяет существование базы данных
- Автоматически закрывает туннель после проверки

**Когда использовать:**
- После настройки подключения к БД на сервере
- Для проверки работоспособности SSH туннеля
- Перед запуском бота для проверки доступности БД

### Скрипт: `scripts/check_db_tunnel.py`

**Назначение:**
Детальная проверка SSH туннеля и подключения к базе данных.

**Запуск:**
```powershell
python scripts/check_db_tunnel.py
```

**Что делает:**
- Показывает конфигурацию SSH (хост, пользователь, порт)
- Проверяет доступность PostgreSQL до создания туннеля
- Создает SSH туннель и проверяет его работу
- Тестирует подключение к БД через туннель
- Показывает статистику БД (количество таблиц)
- Автоматически закрывает туннель после проверки

**Когда использовать:**
- Для диагностики проблем с SSH туннелем
- Для проверки правильности настройки SSH параметров
- Для получения подробной информации о подключении

### Скрипт: `scripts/run_migration.py`

**Назначение:**
Применяет миграции Alembic с автоматическим созданием SSH туннеля при необходимости.

**Запуск:**
```powershell
python scripts/run_migration.py
```

**Что делает:**
- Автоматически создает SSH туннель, если нужно
- Показывает текущую версию миграций
- Применяет все миграции до `head`
- Показывает новую версию после применения
- Автоматически закрывает туннель после завершения

**Когда использовать:**
- После переноса БД на сервер
- После обновления кода с новыми миграциями
- Для синхронизации схемы БД с кодом

### Настройка SSH туннеля

Для работы скриптов с SSH туннелем добавьте в `.env`:

```env
# База данных через SSH туннель
DATABASE_URL=postgresql+asyncpg://bot_user:password@localhost:5432/silent_couple_bot

# SSH настройки
DATABASE_SSH_HOST=your-server-ip
DATABASE_SSH_USER=root
DATABASE_SSH_PORT=22
```

**Важно:**
- Убедитесь, что SSH ключи настроены для автоматического подключения
- Скрипты автоматически создают и закрывают туннель
- Если БД доступна локально, туннель не создается

Подробнее см. [DATABASE_MIGRATION.md](DATABASE_MIGRATION.md)
