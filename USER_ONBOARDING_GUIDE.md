# Пошаговый алгоритм действий для нового пользователя

## Сценарий: Пользователь впервые запускает бота и не имеет пары

### Шаг 1: Запуск бота
**Действие пользователя:** Отправляет команду `/start` боту

**Что происходит:**
- Бот приветствует пользователя
- Показывает сообщение: *"Добро пожаловать! 📄 Ознакомьтесь с политикой конфиденциальности:"*
- Отображается кнопка **"📄 Политика"** для просмотра политики конфиденциальности

---

### Шаг 2: Принятие политики конфиденциальности
**Действие пользователя:** Нажимает кнопку **"Принимаю ✅"**

**Что происходит:**
- Бот сохраняет согласие пользователя
- Показывает сообщение: *"Согласие принято!"*
- Переходит к следующему шагу — выбору режима общения

---

### Шаг 3: Выбор режима общения
**Действие пользователя:** Выбирает один из двух режимов:
- **💬 Чат** — режим с текстовыми сообщениями
- **💔 Безмолвие** — режим без текстовых сообщений (только картинки)

**Что происходит:**
- Бот сохраняет выбранный режим
- Показывает следующий экран — выбор места получения пожеланий

---

### Шаг 4: Выбор места получения пожеланий
**Действие пользователя:** Выбирает, где удобнее получать пожелания:
- **В чате с ботом** — пожелания будут приходить в личные сообщения с ботом
- **В нашем личном чате** — пожелания будут приходить в личный чат с партнёром (требует дополнительной настройки после создания пары)

**Что происходит:**
- Если выбран **"В чате с ботом"** → сразу переходит к шагу 5
- Если выбран **"В нашем личном чате"** → после создания пары нужно будет переслать специальное сообщение в личный чат с партнёром

---

### Шаг 5: Получение ссылки-приглашения
**Действие пользователя:** Получает от бота ссылку-приглашение

**Что происходит:**
- Бот показывает сообщение с информацией о выбранном режиме
- Отображается ссылка-приглашение вида: `https://t.me/bot_name?start=USER_TELEGRAM_ID`
- Показываются кнопки:
  - **"➡️ Поделиться ссылкой"** — для отправки ссылки через Telegram
  - **"📋 Копировать ссылку"** — для копирования ссылки в буфер обмена

**Альтернативный способ:** Пользователь может использовать команду `/create_pair` из меню бота (кнопка меню внизу экрана), чтобы получить ссылку-приглашение в любой момент.

---

### Шаг 6: Отправка ссылки партнёру
**Действие пользователя:** Отправляет ссылку-приглашение своему партнёру через любой удобный способ (Telegram, SMS, email и т.д.)

---

### Шаг 7: Партнёр переходит по ссылке
**Действие партнёра:** Открывает ссылку-приглашение в Telegram

**Что происходит:**
- Бот запускается для партнёра
- Если партнёр также новый пользователь:
  - Показывается приветствие и политика конфиденциальности
  - Партнёр должен принять политику (кнопка **"Принимаю ✅"**)
  - После принятия политики пара создаётся автоматически
- Если партнёр уже имеет аккаунт в боте:
  - Пара создаётся сразу после перехода по ссылке

---

### Шаг 8: Подтверждение создания пары
**Что происходит:**
- Оба пользователя получают уведомление: *"✅ Пара создана! Режим: [выбранный режим]. Демо период: 7 дней."*
- Активируется демо-период на 7 дней
- Пара готова к использованию

---

### Шаг 9 (опционально): Настройка личного чата
**Если на шаге 4 был выбран режим "В нашем личном чате":**

**Действие пользователей:**
1. Оба пользователя получают специальное сообщение с кнопкой **"▶️ Подключить чат"**
2. Один из пользователей пересылает это сообщение в свой личный чат с партнёром
3. В личном чате нажимает кнопку **"▶️ Подключить чат"**
4. Получает подтверждение: *"✅ Чат подключён! Теперь пожелания будут приходить сюда."*

**Что происходит:**
- Бот сохраняет ID личного чата
- Все последующие пожелания будут приходить в этот чат вместо чата с ботом

---

### Шаг 10: Начало использования бота
**После создания пары пользователи могут:**
- Получать автоматические утренние и вечерние запросы на отправку пожеланий (в зависимости от настроек времени в боте)
- Отправлять пожелания партнёру, нажимая кнопки в сообщениях бота
- Просматривать информацию о подписке через команду `/subscription` или кнопку меню **"📊 Подписка"**
- Настраивать никнейм партнёра через команду `/settings` → **"Изменить имя партнера"** (для различения партнёров при множественных парах)

---

## Важные моменты:

1. **Демо-период:** После создания пары автоматически активируется демо-период на 7 дней. В течение этого времени бот работает бесплатно.

2. **Режим общения:** Выбранный режим (Чат или Безмолвие) применяется ко всей паре и определяет формат сообщений.

3. **Место получения пожеланий:** Можно изменить позже в настройках (`/settings`), если изначально был выбран режим "В чате с ботом".

4. **Создание дополнительных пар:** Пользователь может создать несколько пар с разными партнёрами, используя команду `/create_pair` или переходя по разным ссылкам-приглашениям.

5. **Никнеймы партнёров:** Для удобства различения партнёров при множественных парах рекомендуется установить никнеймы через `/settings` → **"Изменить имя партнера"**.

---

## Краткая схема процесса:

```
/start
  ↓
Принятие политики конфиденциальности
  ↓
Выбор режима (Чат / Безмолвие)
  ↓
Выбор места получения пожеланий (Бот / Личный чат)
  ↓
Получение ссылки-приглашения
  ↓
Отправка ссылки партнёру
  ↓
Партнёр переходит по ссылке
  ↓
Пара создана ✅
  ↓
(Опционально) Настройка личного чата
  ↓
Использование бота
```
