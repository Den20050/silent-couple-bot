# Инструкция по проверке пропущенных картинок

## Проблема

При загрузке картинок скрипт `load_images.py` может пропустить некоторые файлы, пометив их как дубликаты. Это происходит когда:
- Telegram возвращает одинаковые `file_id` для разных картинок
- Картинка уже была загружена ранее
- Произошла ошибка при проверке дубликатов

**Важно:** Файлы со списком пропущенных картинок (`skipped_*.txt`) создаются автоматически только при запуске `load_images.py` **после** добавления этой функциональности. Если вы запускали скрипт раньше, этих файлов может не быть.

## Решение

### Шаг 1: Проверка пропущенных картинок

**Вариант А: Если есть файлы со списком пропущенных картинок**

Если файлы `image/skipped_*.txt` существуют, используйте:

```bash
python scripts/analyze_skipped.py
```

**Вариант Б: Если файлов нет (скрипт запускался до добавления функциональности)**

Сравните количество файлов в папках с количеством записей в БД:

```bash
python scripts/find_missing_images.py
```

или

```bash
python scripts/check_images_count.py
```

Эти скрипты покажут разницу между количеством файлов в папках и количеством записей в БД.

**Что покажет скрипт:**
- Количество пропущенных картинок (утренних и вечерних)
- Причины пропуска (дубликат file_id, дубликат hash и т.д.)
- Сколько из них реальные дубликаты (file_id уже в БД)
- Сколько нужно загрузить заново

**Пример вывода:**
```
📄 Найден файл с пропущенными утренними картинками: image/skipped_morning_morning.txt
   Найдено пропущенных файлов: 150

🌅 Анализ утренних картинок:
   Всего пропущено: 150

   Причины пропуска:
     - Duplicate file_id in pre-loaded set: 100
     - Duplicate hash in this session: 50

   Статистика:
     - С file_id в БД (реальные дубликаты): 100
     - Без file_id или file_id не в БД (нужно загрузить): 50
     - Файлы существуют на диске: 150
     - Файлы отсутствуют на диске: 0
```

### Шаг 2: Дозагрузка пропущенных картинок

**Вариант А: Загрузить только те, которые не являются дубликатами**

```bash
python scripts/reload_skipped_images.py <your_chat_id>
```

Этот скрипт проверяет каждый файл и загружает только те, чьи `file_id` отсутствуют в БД.

**Вариант Б: Загрузить ВСЕ пропущенные файлы (увеличить количество картинок)**

Если вы хотите увеличить количество картинок в БД, загрузив все пропущенные файлы (даже если они дубликаты):

```bash
python scripts/reload_all_skipped.py <your_chat_id>
```

**Важно:**
- Этот скрипт загружает ВСЕ пропущенные файлы без проверки дубликатов
- Telegram может вернуть одинаковые `file_id` для одинаковых картинок
- Но при повторной загрузке Telegram может вернуть новые `file_id`
- Это увеличит количество картинок в БД
- Вероятность того, что бот отправит дубликаты подряд минимальна

**Что делает скрипт `reload_skipped_images.py`:**
1. Читает список пропущенных файлов из `image/skipped_morning_morning.txt` и `image/skipped_evening_evening.txt`
2. Для каждого файла:
   - Проверяет, существует ли `file_id` в БД
   - Если `file_id` есть в БД - пропускает (это реальный дубликат)
   - Если `file_id` нет в БД - загружает файл заново
3. Сохраняет новые `file_id` в БД
4. Показывает статистику загрузки

**Что делает скрипт `reload_all_skipped.py`:**
1. Читает список пропущенных файлов из `image/skipped_morning_morning.txt` и `image/skipped_evening_evening.txt`
2. Загружает ВСЕ файлы без проверки дубликатов
3. Сохраняет все новые `file_id` в БД (даже если они дубликаты)
4. Увеличивает количество картинок в БД
5. Показывает статистику загрузки

**Пример вывода:**
```
📄 Найден файл с пропущенными утренними картинками: image/skipped_morning_morning.txt
   Найдено пропущенных файлов: 150

🌅 Обрабатываем утренние картинки...

🔍 Проверяем 150 пропущенных файлов...
  ✅ Загружено: 10 файлов
  📊 Проверено: 50/150, загружено: 10, пропущено: 40
  ✅ Загружено: 20 файлов
  📊 Проверено: 100/150, загружено: 20, пропущено: 80
  ✅ Загружено: 30 файлов
  📊 Проверено: 150/150, загружено: 30, пропущено: 120
   ✅ Загружено: 30, пропущено (дубликаты): 120

✅ Обработка завершена!
   Загружено новых файлов: 30
   Пропущено (дубликаты): 120

   Всего в БД:
     Утренних: 944
     Вечерних: 645
     Всего: 1589
```

## Важные замечания

- ⚠️ **Файлы со списком пропущенных картинок создаются автоматически** при запуске `load_images.py`
- ⚠️ **Скрипт использует задержку 5 секунд** между загрузками для безопасности
- ⚠️ **Скрипт автоматически увеличивает задержку** при обнаружении ограничений Telegram API
- ⚠️ **Если файлы не найдены**, скрипты сообщат об этом и покажут, где они должны находиться

## Когда использовать

Используйте эти скрипты, если:
- Скрипт загрузки пропустил много картинок (более 50-100)
- Вы хотите убедиться, что все картинки загружены
- Вы подозреваете, что некоторые картинки были пропущены ошибочно

## Полный процесс

### Если файлы со списком пропущенных картинок есть:

```bash
# 1. Проанализируйте пропущенные картинки
python scripts/analyze_skipped.py

# 2. Если нужно - догрузите пропущенные картинки
python scripts/reload_skipped_images.py <your_chat_id>

# 3. Проверьте итоговое количество
python scripts/check_images_count.py
```

### Если файлов со списком пропущенных картинок нет:

```bash
# 1. Проверьте разницу между файлами и БД
python scripts/find_missing_images.py
# или
python scripts/check_images_count.py

# 2. Если есть разница - запустите загрузку заново
# Скрипт автоматически пропустит уже загруженные картинки
python scripts/load_images.py <your_chat_id>

# 3. После загрузки файлы со списком пропущенных будут созданы автоматически
# Теперь можно использовать analyze_skipped.py и reload_skipped_images.py
```
