# Настройка периода демо режима через переменные окружения

## Описание

Период демо режима теперь настраивается через переменную окружения `TRIAL_PERIOD_DAYS` в файле `.env`.

## Настройка

### 1. Добавьте переменную в `.env`

```env
# Период демо режима (дни)
# Продолжительность пробного периода для новых пар
# По умолчанию: 7 дней
TRIAL_PERIOD_DAYS=7
```

### 2. Валидация

- Минимальное значение: **1 день**
- Максимальное значение: **365 дней**
- По умолчанию: **7 дней** (если не указано)

### 3. Примеры значений

```env
# Стандартный демо период (7 дней)
TRIAL_PERIOD_DAYS=7

# Короткий демо период (3 дня)
TRIAL_PERIOD_DAYS=3

# Длинный демо период (14 дней)
TRIAL_PERIOD_DAYS=14

# Очень длинный демо период (30 дней)
TRIAL_PERIOD_DAYS=30
```

## Технические детали

### Изменения в коде

1. **`src/core/config.py`**:
   - Добавлено поле `trial_period_days: int` с валидацией (1-365 дней)
   - Значение по умолчанию: 7 дней

2. **`src/core/constants.py`**:
   - `TRIAL_PERIOD_DAYS` теперь берется из `settings.trial_period_days`
   - Обратная совместимость сохранена (все места, где используется `TRIAL_PERIOD_DAYS`, продолжают работать)

3. **`src/bot/handlers/start.py`**:
   - Добавлена функция `_get_days_text()` для правильного склонения слова "день"
   - Сообщения о создании пары теперь используют динамическое значение из настроек

4. **`env.example`**:
   - Добавлена переменная `TRIAL_PERIOD_DAYS=7` с комментариями

## Использование

`TRIAL_PERIOD_DAYS` используется в следующих местах:

1. **Создание подписки** (`src/bot/handlers/start.py`):
   - При создании пары устанавливается `period_end = today + TRIAL_PERIOD_DAYS`

2. **Отображение информации о подписке** (`src/bot/handlers/subscription.py`, `src/bot/handlers/menu.py`):
   - Расчет оставшихся дней демо периода
   - Отображение в сообщениях пользователям

3. **Сообщения о создании пары** (`src/bot/handlers/start.py`):
   - Динамическое отображение периода демо в сообщениях

## Важные замечания

- Изменение `TRIAL_PERIOD_DAYS` влияет только на **новые пары**
- Существующие пары сохраняют свой `period_end`, установленный при создании
- После изменения значения в `.env` необходимо **перезапустить бота** для применения изменений

## Пример использования

1. Установите `TRIAL_PERIOD_DAYS` в `.env`
2. Перезапустите бота
3. Новые пары будут создаваться с указанным периодом демо
