1. Описание проекта
Silent-Couple-Bot — Telegram-бот для пар, который каждый день отправляет уникальные картинки «Доброе утро» и «Спокойной ночи» в случайное время внутри окна 07:30-08:30 и 21:30-22:30 по часовому поясу каждого пользователя. Нажатие на inline-кнопку «💌» = «молчаливое мигание» партнёру.
Ключевые особенности:
Уникальность картинок: 30 дней для каждого пользователя в паре (A и B получают разные)
Рандомное время: ±30 минут от центра окна для естественности
Без текста: только картинки и одна кнопка
Меню: команды в Menu Button (≡) без личного кабинета
Подписка: 199 ₽/мес, trial 7 дней
152-ФЗ + GDPR: согласие, локализация, удаление за 3 дня

3. User Journey (полный алгоритм)

1. User A нажимает START
2. Бот: «Ознакомьтесь с политикой обработки ПДн 📄»
   [📄 Политика] → открывает Telegra.ph
3. User возвращается → бот показывает:
   «Ознакомились? Теперь можете принять»
   [Принимаю ✅] ← inline-кнопка
4. User нажимает ✅ → бот:
   - Сохраняет tg_id, username, IP, consent_dt
   - Авто-определяет utc_offset (по времени нажатия)
   - Генерирует invite-ссылку t.me/YourBot?start=REF_AAA
   - Показывает: «Пригласите партнёра» [Поделиться]

3.2. Приглашение партнёра
5. User B заходит по ссылке → повторяет шаги 2-4
6. Бот создаёт:
   - Запись в pairs (uid_a, uid_b)
   - Trial-subscription (status='trial', trial_end=+7д)
   - Отправляет обоим: «Пара создана!»

3.3. Ежедневная рассылка

7. Каждые 30 мин cron проверяет:
   - UTC время = 07:30-08:30 (UT) и 21:30-22:30 (UT)
   - Для каждой пары генерирует random next_send_at внутри окна
   - Отправляет картинку A → uid_a, картинку B → uid_b
   - Сохраняет в pings и pic_ledger
8. User получает картинку + кнопку «💌»
9. User нажимает 💌 → кнопка исчезает, партнёр получает такую же картинку + «Ваш партнёр на связи»

3.4. Меню управления (Menu Button ≡)

10. User нажимает ≡ Menu → выбирает:
    - Показать меню → inline-сообщение с подпиской и кнопками
    - Оплатить 199 ₽ → переходит в YooKassa checkout
    - Удалить → мгновенное удаление ПДн

3.5. Оплата и продление

11. Trial заканчивается → бот отправляет invoice
12. User оплачивает → YooKassa webhook → sub.active, current_period_end=+30д
13. Каждый день проверяем списания → если failed, меняем статус на past_due

5. SQL-схема БД

Файл: init/01-schema.sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    tg_id BIGINT UNIQUE NOT NULL,
    tg_username TEXT,
    utc_offset SMALLINT DEFAULT 3,
    next_send_at TIMESTAMPTZ,
    consent BOOLEAN DEFAULT FALSE,
    consent_dt TIMESTAMPTZ,
    consent_ip INET,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE pairs (
    id BIGSERIAL PRIMARY KEY,
    uid_a BIGINT REFERENCES users(id),
    uid_b BIGINT REFERENCES users(id),
    status TEXT DEFAULT 'trial',
    trial_end DATE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE subscriptions (
    id BIGSERIAL PRIMARY KEY,
    pair_id BIGINT REFERENCES pairs(id),
    payer_uid BIGINT REFERENCES users(id),
    external_id TEXT,
    status TEXT DEFAULT 'trial',
    current_period_end TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE pings (
    id BIGSERIAL,
    pair_id BIGINT REFERENCES pairs(id),
    sender_uid BIGINT REFERENCES users(id),
    type TEXT,
    sent_at TIMESTAMPTZ DEFAULT NOW()
) PARTITION BY RANGE (sent_at);

CREATE TABLE pics_pool (
    file_id TEXT PRIMARY KEY,
    type TEXT  -- 'morning' | 'evening'
);

CREATE TABLE pic_ledger (
    pair_id BIGINT,
    file_id TEXT,
    role TEXT,  -- 'A' | 'B'
    sent_at DATE,
    PRIMARY KEY (pair_id, file_id, role)
);

CREATE TABLE refunds (
    id BIGSERIAL PRIMARY KEY,
    sub_id BIGINT REFERENCES subscriptions(id),
    amount_cents INT,
    reason TEXT,
    refund_id TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

5.2. Индексы

CREATE INDEX idx_pairs_status_trial ON pairs(status, trial_end);
CREATE INDEX idx_subs_period_end ON subscriptions(current_period_end, status);
CREATE INDEX idx_pings_pair_date ON pings(pair_id, sent_at);
CREATE INDEX idx_ledger_pair_date ON pic_ledger(pair_id, sent_at);

8.1. Загрузка картинок в Telegram
Файл: scripts/load_pics_to_tg.js

const fs = require('fs');
const axios = require('axios');

const TG_TOKEN = process.env.TG_BOT_TOKEN;
const PIC_DIR = '/opt/silent-bot/pics';

async function uploadToTelegram(filePath, type) {
  const form = new FormData();
  form.append('photo', fs.createReadStream(filePath));
  const {data} = await axios.post(`https://api.telegram.org/bot${TG_TOKEN}/sendPhoto`, form, {
    headers: form.getHeaders(),
    params: {
      chat_id: process.env.ADMIN_TG_ID,
      caption: type
    }
  });
  return data.result.photo[0].file_id;
}

async function main() {
  const files = fs.readdirSync(PIC_DIR).filter(f => f.endsWith('.jpg'));
  const pool = [];
  for (const file of files) {
    const type = file.includes('morning') ? 'morning' : 'evening';
    const fileId = await uploadToTelegram(`${PIC_DIR}/${file}`, type);
    pool.push({file_id: fileId, type});
    console.log(`${file} → ${fileId}`);
  }
  // Сохранить в БД
  const {Client} = require('pg');
  const pg = new Client({connectionString: process.env.POSTGRES_URL});
  await pg.connect();
  for (const p of pool) {
    await pg.query('INSERT INTO pics_pool VALUES ($1, $2) ON CONFLICT DO NOTHING', [p.file_id, p.type]);
  }
  await pg.end();
}

main().catch(console.error);

#!/bin/bash

Арендуйте VPS в РФ (MTS Cloud, 2 vCPU, 4 GB, Ubuntu 22.04)
Купите домен bot-domain.ru, настройте A-запись на IP VPS
Создайте бота в @BotFather, получите токен
Зарегистрируйтесь в YooKassa, получите ShopId + SecretKey
Шаг 1: Установка
ssh root@bot-domain.ru
apt update && apt install docker.io docker-compose -y
mkdir /opt/silent-bot && cd /opt/silent-bot
# Скопируйте все файлы проекта
cp -r /path/to/silent-couple-bot/* .
cp .env.example .env
nano .env  # Заполните все переменные

Шаг 2: Запуск
docker-compose up -d
docker-compose logs -f n8n  # Смотрим, пока не завершится миграция

Шаг 3: Инициализация БД
docker exec -it n8n_db psql -U n8n -d n8n -f /docker-entrypoint-initdb.d/01-schema.sql
docker exec -it n8n_db psql -U n8n -d n8n -f /docker-entrypoint-initdb.d/02-indexes.sql
docker exec -it n8n_db psql -U n8n -d n8n -f /docker-entrypoint-initdb.d/03-partitions.sql

Шаг 4: Настройка N8N
Откройте https://bot-domain.ru:5678
Войдите с ADMIN_USER/ADMIN_PASS
Settings → Community nodes → Install n8n-nodes-postgres-simplified
Settings → Credentials → Добавьте:
PostgreSQL (host=postgres, user=n8n, pass=...)
Telegram (token=TG_BOT_TOKEN)
YooKassa (shopId, secret)
Minio (endpoint=minio:9000, key, secret)
Settings → Import → Загрузите workflows W1-W10

Шаг 5: Загрузка картинок
# Положите 1000 jpeg в /opt/silent-bot/pics/
mkdir -p /opt/silent-bot/pics
# Скопируйте туда ваши morning/ и evening/ картинки
docker exec -it n8n_main node /workflows/scripts/load_pics_to_tg.js

Шаг 6: Настройка Telegram
# Установите webhook
curl -v "https://api.telegram.org/bot${TG_BOT_TOKEN}/setWebhook?url=https://${DOMAIN}/webhook/telegram"
# Установите команды Menu Button
curl -v "https://api.telegram.org/bot${TG_BOT_TOKEN}/setMyCommands" \
  -d 'commands=[{"command":"menu","description":"Показать меню"},{"command":"pay","description":"Оплатить 199 ₽"},{"command":"delete","description":"Удалить себя"}]'

Шаг 7: Тестирование
Пишите боту /start
Проходите flow: политика → принимаю → приглашение
С другого аккаунта переходите по ссылке
Ждите 07:30-08:30 → проверьте картинки и кнопки
Нажмите 💌 → проверьте, что у партнёра кнопка исчезла

10. Мониторинг и поддержка
10.1. UptimeRobot
Добавьте монитор https://bot-domain.ru/health (каждые 5 мин)
Настройте алерт в Telegram при дауне >5 мин
10.2. Grafana
Импортируйте monitoring/grafana-dashboard.json
Dashboard показывает:
Количество пар, отправленных картинок, успешных tap
Uptime, p99 latency, queue depth
Количество refunds
10.3. Алерты
Telegram: отправляйте в канал #alerts при:
Queue depth > 1000
p99 latency > 2 сек
Postgres replication lag > 30 сек
10.4. Ежедневные задачи
Бэкап: cron 0 4 * * * /opt/silent-bot/scripts/daily_backup.sh
Чистка: W10 автоматически удаляет pings >90 дней, ledger >30 дней


11. Юридика и соответствие
11.1. 152-ФЗ (РФ)
Локализация: VPS и БД в РФ (МТС, Selectel)
Согласие: inline-кнопка, фиксация IP и даты
Удаление: команда /delete → удаление всех ПДн ≤ 3 дней
Регистрация в РКН: не требуется (<100k субъектов)
Оферта: docs/oferta.md (публичная)
11.2. GDPR (ЕС)
Минимизация: только tg_id, utc_offset, dates
Согласие: explicit, before processing
Right to erasure: /delete → instant erase
DPA: подписан с YooKassa
Privacy policy: docs/privacy_telegra.md (Telegra.ph)
11.3. Возврат средств
Условие: простой сервиса >24 часов подряд
Доказательство: UptimeRobot + логи n8n + Grafana
Процедура: админ нажимает «Approve refund» в W8 → YooKassa API → уведомление user
