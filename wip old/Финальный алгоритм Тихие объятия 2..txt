Финальный алгоритм "Тихие объятия 2.0"
Время 07:30-08:30 (случайное для пары)
Бот отправляет обоим одно и то же сообщение-запрос:
Copy
Хотите отправить близкому человеку пожелание с "Добрым утром"?
[Отправить в ответ]
(кнопка inline, callback_data = request_morning_${pair_id}_${user_id})
Сценарий 1: User A нажимает первым (08:05)
Бот редактирует сообщение User A:
✅ Вы отправили пожелание
(кнопка исчезает)
Бот редактирует сообщение User B:
Ваш партнёр уже отправил пожелание
(кнопка исчезает, чтобы B не мог тоже инициировать)
Бот отправляет User B картинку morning_123.jpg + кнопка:
[Отправить в ответ]
(теперь B отвечает на полученное пожелание)
В БД ставится флаг pair.morning_initiator = uid_a (кто первый нажал)
Сценарий 2: User B нажимает первым (08:12)
Абсолютно симметрично:
Редактируется сообщение User B → ✅ Вы отправили пожелание
Редактируется сообщение User A → Ваш партнёр уже отправил пожелание
User A получает картинку morning_456.jpg + кнопка [Отправить в ответ]
Сценарий 3: Второй отвечает на полученную картинку (08:20)
User B нажимает [Отправить в ответ] под картинкой morning_123.jpg
Бот редактирует сообщение User B (убирает кнопку):
✅ Вы ответили на пожелание
Бот отправляет User A картинку morning_789.jpg (новую, другую)
Все кнопки исчезают, цепочка закончена
Сценарий 4: Конфликт одновременного нажатия (редко)
Если оба нажали в одну секунду:
БД-констрейнт WHERE pair.locker IS NULL позволит пройти только первому
Второй получит telegram.Error "Message is not modified" → ловим и игнорируем
Сообщение второго автоматически редактируется в "Ваш партнёр уже отправил пожелание"
📌 Технические детали реализации
1. В W3 (Morning Sender) — изменяем отправку
JavaScript
Copy
// Отправляем обоим одинаковое сообщение-запрос
await telegram.sendMessage({
  chat_id: uid_a,
  text: "Хотите отправить близкому человеку пожелание с \"Добрым утром\"?",
  reply_markup: { inline_keyboard: [[{text: "Отправить в ответ", callback_data: `request_morning_${pair_id}_${uid_a}`}]] }
});

await telegram.sendMessage({
  chat_id: uid_b,
  text: "Хотите отправить близкому человеку пожелание с \"Добрым утром\"?",
  reply_markup: { inline_keyboard: [[{text: "Отправить в ответ", callback_data: `request_morning_${pair_id}_${uid_b}`}]] }
});
2. В W5 (Callback) — добавляем новый обработчик
JavaScript
Copy
if (data.startsWith('request_morning')) {
  // Попытка захватить пару
  const result = await $postgres.query(
    "UPDATE pairs SET initiator_uid = $1 WHERE id = $2 AND initiator_uid IS NULL RETURNING *;",
    [user_id, pair_id]
  );
  
  if (result.length === 0) {
    // Кто-то уже захватил
    await telegram.editMessageText({
      chat_id: user_id,
      text: "Ваш партнёр уже отправил пожелание"
    });
    return [];
  }
  
  // Успех — редактируем сообщения
  await telegram.editMessageText({
    chat_id: user_id,
    text: "✅ Вы отправили пожелание"
  });
  
  // Редактируем сообщение партнёра
  const partner_id = (uid_a === user_id) ? uid_b : uid_a;
  await telegram.editMessageText({
    chat_id: partner_id,
    text: "Ваш партнёр уже отправил пожелание"
  });
  
  // Отправляем картинку партнёру
  await telegram.sendPhoto({
    chat_id: partner_id,
    photo: file_id,
    reply_markup: { inline_keyboard: [[{text: "Отправить в ответ", callback_data: `tap_morning_${pair_id}_${partner_id}`}]] }
  });
}
