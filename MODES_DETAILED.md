## Общее описание

Бот поддерживает два режима общения, которые выбираются при создании пары. Режим можно изменить позже в настройках (`/settings`). Режим определяет:

- Тексты всех сообщений бота
- Стиль общения (формальный или неформальный)
- Наличие Micro-Surprise (случайные тёплые подписи)
- Тон напоминаний и предупреждений

**Важно:** Оба режима работают одинаково с технической точки зрения:
- Оба пользователя получают запросы на отправку картинок
- Первый, кто нажмёт кнопку, становится инициатором
- Второй должен ответить своей картинкой
- Напоминания и предупреждения работают одинаково

**Единственное различие** — это тексты сообщений и наличие Micro-Surprise в Chat Mode.

### Выбор места доставки картинок

При создании пары пользователи могут выбрать, **куда будут приходить картинки с пожеланиями**:

1. **В чате с ботом** (`bot_dm`) — картинки приходят в личный чат каждого пользователя с ботом (по умолчанию)
2. **В личном чате пары** (`pair_dm`) — картинки приходят напрямую в личный диалог между партнёрами (A↔B)

**Особенности режима `pair_dm`:**
- Бот один раз получает `chat_id` личного чата пары и сохраняет его
- Все картинки с пожеланиями отправляются в этот чат
- Кнопка «Отправить в ответ» остаётся только в чате с ботом (для удобства ответа)
- Бот **не сохраняет** текст сообщений участников пары (только свои собственные сообщения)
- В подписи к картинке добавляется имя отправителя: `— от {имя}`

**Важно:** Выбор места доставки можно изменить позже в настройках (`/settings`). Режим общения (Chat/Silent) также можно изменить в настройках.

## Chat Mode (💬 Часто общаемся)

### Для кого

Для пар, которые:
- Часто общаются в личных чатах
- Хотят более дружелюбный и неформальный стиль общения
- Ценят разнообразие в сообщениях (Micro-Surprise)

### Особенности

1. **Неформальные тексты** — более дружелюбные и естественные формулировки
2. **Micro-Surprise** — случайные тёплые подписи к картинкам (примерно раз в 3-4 дня)
3. **Более личный тон** — подписи звучат как обращение к близкому человеку

### Тексты сообщений

#### 1. Запросы на отправку картинок

**Утро (07:30-08:30 UTC):**
```
Утро! Отправьте доброе пожелание в ответ:
[Кнопка: "Отправить картинку"]
```

**Вечер (21:30-22:30 UTC):**
```
Вечер! Отправьте пожелание на ночь:
[Кнопка: "Отправить картинку"]
```

**Примечание:** Запросы всегда приходят в **личный чат с ботом**, независимо от выбранного места доставки картинок.

#### 2. Подписи к картинкам (для получателя)

**Утро:**
- **Стандартная подпись:** "Доброе утро, солнце ☀️"
- **Micro-Surprise** (примерно раз в 3-4 дня, если прошло ≥72 часов с последнего):
  - "Доброе утро ☀️… а теперь иди целуй меня"
  - "Твоё утро начинается со мня — и это прекрасно"
  - "Доброе утро, солнце ☀️"

**Вечер:**
- **Стандартная подпись:** "Спокойной ночи, мой человек 🌙"
- **Micro-Surprise** (примерно раз в 3-4 дня, если прошло ≥72 часов с последнего):
  - "Засыпай — я рядом, даже если молчу"
  - "Спокойной ночи… и не думай о ком-то другом ❤️"
  - "Спокойной ночи, мой человек 🌙"

**Особенность для режима `pair_dm`:** К подписи добавляется имя отправителя:
- "Доброе утро, солнце ☀️\n— от {имя_отправителя}"
- "Спокойной ночи, мой человек 🌙\n— от {имя_отправителя}"

**Как работает Micro-Surprise:**
- При формировании сообщения генерируется случайное число от 1 до 4
- Если выпадает "1" **И** с момента последнего сюрприза прошло ≥ 72 часов → используется случайная подпись из списка
- Иначе используется стандартная подпись
- Время последнего сюрприза сохраняется в `daily_state.last_surprise_at`

#### 3. Подпись при ответе (для инициатора)

Когда получатель отвечает на картинку, инициатор получает картинку с подписью:

```
Тебе ответили ❤️
```

#### 4. Напоминания получателю (3, 6, 9 часов после отправки)

Если получатель не ответил в течение указанного времени:

```
Тебя ждут ❤️
[Кнопка: "Отправить в ответ"]
```

#### 5. Предупреждения инициатору (начиная с 10 часов, затем каждый час)

**Первое предупреждение (10 часов):**
```
⚠️ @{username} не отвечает, возможно, стоит написать вручную.
[Кнопка: "❌ Отменить напоминания"]
```

**Последующие предупреждения (11, 12, 13, ..., 24 часа):**
- Отправляются каждый час до 24 часов с момента отправки картинки
- Текст тот же, что и для первого предупреждения
- Инициатор может отменить предупреждения, нажав кнопку

#### 6. Еженедельная статистика (каждое воскресенье в 00:00 UTC)

```
Уже {days_count} дней подряд вы засыпаете и просыпаетесь вместе ❤️
```

Где `{days_count}` — количество дней с завершёнными обменами (утренними или вечерними).

#### 7. Напоминание о поделиться ботом (ежедневно в 14:00 UTC)

Случайный вариант из списка:

```
А у ваших близких людей тоже есть человек, которому хочется сказать 
«я ок» без слов? Перешлите бота — пусть у них тоже будет 
свой маленький ритуал.
```

[Кнопка: "📤 Переслать бота"]

## Silent Mode (💔 Редко)

### Для кого

Для пар, которые:
- Редко общаются в течение дня
- Нужен простой сигнал о том, что всё в порядке
- Предпочитают формальный и нейтральный стиль общения
- Фокус на безопасности и подтверждении благополучия

### Особенности

1. **Формальные тексты** — нейтральные и деловые формулировки
2. **Фокус на безопасности** — подписи подчёркивают, что всё в порядке
3. **Без Micro-Surprise** — только стандартные подписи
4. **Мягкие напоминания** — акцент на заботе без слов

### Тексты сообщений

#### 1. Запросы на отправку картинок

**Утро (07:30-08:30 UTC):**
```
Хотите отправить пожелание с "Добрым утром"?
[Кнопка: "Отправить картинку"]
```

**Вечер (21:30-22:30 UTC):**
```
Хотите отправить пожелание с "Спокойной ночи"?
[Кнопка: "Отправить картинку"]
```

**Примечание:** Запросы всегда приходят в **личный чат с ботом**, независимо от выбранного места доставки картинок.

#### 2. Подписи к картинкам (для получателя)

**Утро:**
```
Со мной всё в порядке ❤️
```

**Вечер:**
```
Я в безопасности, спокойной ночи ❤️
```

**Важно:** В Silent Mode нет Micro-Surprise — всегда используются стандартные подписи.

**Особенность для режима `pair_dm`:** К подписи добавляется имя отправителя:
- "Со мной всё в порядке ❤️\n— от {имя_отправителя}"
- "Я в безопасности, спокойной ночи ❤️\n— от {имя_отправителя}"

#### 3. Подпись при ответе (для инициатора)

Когда получатель отвечает на картинку, инициатор получает картинку с подписью:

**Утро:**
```
Доброе утро ❤️
```

**Вечер:**
```
Спокойной ночи ❤️
```

#### 4. Напоминания получателю (3, 6, 9 часов после отправки)

Если получатель не ответил в течение указанного времени:

```
Если есть секунда — ответьте картинкой, чтобы он не беспокоился.
[Кнопка: "Отправить в ответ"]
```

#### 5. Предупреждения инициатору (начиная с 10 часов, затем каждый час)

**Первое предупреждение (10 часов):**
```
⚠️ @{username} не отвечает, воспользуйтесь другим способом узнать, всё ли у него в порядке.
[Кнопка: "❌ Отменить напоминания"]
```

**Последующие предупреждения (11, 12, 13, ..., 24 часа):**
- Отправляются каждый час до 24 часов с момента отправки картинки
- Текст тот же, что и для первого предупреждения
- Инициатор может отменить предупреждения, нажав кнопку

**Важно:** В Silent Mode предупреждения подчёркивают необходимость проверить благополучие партнёра другим способом.

#### 6. Еженедельная статистика (каждое воскресенье в 00:00 UTC)

```
Вы уже {days_count} дней тихо проверяете друг друга. Это забота без слов.
```

Где `{days_count}` — количество дней с завершёнными обменами (утренними или вечерними).

```
привычка «просто знать, что всё ок» — можете тихо поделиться ботом.
```

**Вариант 2:**

## Технические детали

### Хранение режима и места доставки

Режим и место доставки сохраняются в базе данных:
- **Таблица `pairs`:** 
  - поле `mode` (`'chat'` или `'silent'`)
  - поле `delivery_chat` (`'bot_dm'` или `'pair_dm'`, по умолчанию `'bot_dm'`)
  - поле `private_chat_id` (BigInteger, nullable) — ID личного чата пары (заполняется при выборе `pair_dm`)
- **Таблица `users`:** поле `preferred_mode` (используется при создании пары)

### Определение режима в коде

Режим проверяется через `pair.mode`:

```python
if pair.mode == "chat":
    # Chat Mode логика
    text = get_message("WORKER_MORNING_REQUEST_CHAT")
    caption = get_message("CAPTION_CHAT_MORNING")
else:
    # Silent Mode логика
    text = get_message("WORKER_MORNING_REQUEST_SILENT")
    caption = get_message("CAPTION_SILENT_MORNING")
```

### Micro-Surprise реализация

**Функция:** `get_caption_with_surprise()` в `src/bot/handlers/callbacks.py`

**Логика:**
1. Проверяется режим пары — если не `"chat"`, возвращается стандартная подпись
2. Для Chat Mode:
   - Генерируется случайное число от 1 до 4
   - Если выпадает "1" **И** прошло ≥72 часов с последнего сюрприза → используется случайная подпись
   - Иначе используется стандартная подпись
3. Время последнего сюрприза сохраняется в `daily_state.last_surprise_at`

**Использование:**
- При отправке картинки инициатором получателю
- При ответе получателя инициатору (только для Chat Mode)

### Все тексты сообщений

Все тексты хранятся в `src/core/messages.py` в классе `Messages`:

**Chat Mode:**
- `WORKER_MORNING_REQUEST_CHAT` — запрос утром
- `WORKER_EVENING_REQUEST_CHAT` — запрос вечером
- `CAPTION_CHAT_MORNING` — подпись утром (стандартная)
- `CAPTION_CHAT_EVENING` — подпись вечером (стандартная)
- `RESPONSE_RECEIVED_CHAT` — подпись при ответе
- `REMINDER_CHAT_MODE` — напоминание получателю
- `WARNING_CHAT_MODE` — предупреждение инициатору
- `WEEK_SUMMARY_CHAT` — еженедельная статистика

**Silent Mode:**
- `WORKER_MORNING_REQUEST_SILENT` — запрос утром
- `WORKER_EVENING_REQUEST_SILENT` — запрос вечером
- `CAPTION_SILENT_MORNING` — подпись утром
- `CAPTION_SILENT_EVENING` — подпись вечером
- `RESPONSE_MORNING_SILENT` — подпись при ответе (утро)
- `RESPONSE_EVENING_SILENT` — подпись при ответе (вечер)
- `REMINDER_SILENT_MODE` — напоминание получателю
- `WARNING_SILENT_MODE` — предупреждение инициатору
- `WEEK_SUMMARY_SILENT` — еженедельная статистика

**Micro-Surprise подписи:**
- `MICRO_SURPRISE_MORNING_CAPTIONS` — список утренних подписей (в `src/core/constants.py`)
- `MICRO_SURPRISE_EVENING_CAPTIONS` — список вечерних подписей (в `src/core/constants.py`)

### Временные окна

Оба режима используют одинаковые временные окна (настраиваются через переменные окружения):

- **Утро:** `MORNING_START_TIME` - `MORNING_END_TIME` (по умолчанию 07:30-08:30 UTC)
- **Вечер:** `EVENING_START_TIME` - `EVENING_END_TIME` (по умолчанию 21:30-22:30 UTC)

**Важно:** Бот учитывает часовой пояс каждого пользователя. Если пользователь находится в UTC+3, то утреннее окно для него будет 10:30-11:30 по местному времени.

### Логика отправки картинок

В зависимости от выбранного места доставки (`delivery_chat`):

**Режим `bot_dm` (по умолчанию):**
- Картинки отправляются в личный чат каждого пользователя с ботом (`recipient.id`)
- Кнопка «Отправить в ответ» прикрепляется к сообщению с картинкой

**Режим `pair_dm`:**
- Картинки отправляются в личный чат пары (`pair.private_chat_id`)
- К подписи добавляется имя отправителя: `— от {sender.first_name}`
- Кнопка «Отправить в ответ» остаётся в чате с ботом (не прикрепляется к картинке в личном чате)
- При ответе картинка отправляется туда же, куда пришла первая (в `pair.private_chat_id`)

**Код отправки:**
```python
target_chat = (
    pair.private_chat_id
    if pair.delivery_chat == DeliveryChat.PAIR_DM and pair.private_chat_id
    else recipient.id
)
await bot.send_photo(chat_id=target_chat, ...)
```

### Напоминания и предупреждения

Оба режима используют одинаковую логику напоминаний:

- **Напоминания получателю:** 3, 6, 9 часов после отправки картинки
- **Предупреждения инициатору:** начиная с 10 часов, затем каждый час до 24 часов

Различаются только тексты сообщений.

## Примеры полного цикла обмена

### Chat Mode — Утренний обмен (режим `bot_dm`)

**07:30 UTC — Бот отправляет запросы обоим пользователям:**

Пользователь А и Пользователь Б получают в чате с ботом:
```
Утро! Отправьте доброе пожелание в ответ:
[Кнопка: "Отправить картинку"]
```

**07:35 UTC — Пользователь А нажимает кнопку первым:**

Пользователь А видит в чате с ботом:
```
✅ Вы отправили пожелание
```

Пользователь Б получает картинку в чате с ботом с подписью:
```
Доброе утро, солнце ☀️
```
(или случайная подпись из Micro-Surprise, если прошло ≥72 часов)

[Кнопка: "Отправить в ответ"]

**08:00 UTC — Пользователь Б отвечает:**

Пользователь Б видит в чате с ботом:
```
✅ Вы ответили на пожелание
```

Пользователь А получает картинку в чате с ботом с подписью:
```
Тебе ответили ❤️
```

**Обмен завершён!**

### Chat Mode — Утренний обмен (режим `pair_dm`)

**07:30 UTC — Бот отправляет запросы обоим пользователям:**

Пользователь А и Пользователь Б получают в чате с ботом:
```
Утро! Отправьте доброе пожелание в ответ:
```

## Заключение

Оба режима работают одинаково с технической точки зрения, но различаются стилем общения:

- **Chat Mode** — для пар, которые часто общаются и ценят неформальный стиль
- **Silent Mode** — для пар, которые редко общаются и нужен простой сигнал о благополучии

Режим выбирается при создании пары, но его можно изменить позже в настройках (`/settings`). Это позволяет боту адаптировать все сообщения под стиль общения конкретной пары и даёт гибкость для изменения предпочтений.

Дополнительно, пары могут выбрать место доставки картинок:
- **В чате с ботом** (`bot_dm`) — удобно для тех, кто предпочитает получать пожелания в отдельном чате
- **В личном чате пары** (`pair_dm`) — удобно для тех, кто хочет видеть пожелания прямо в общем диалоге

Выбор места доставки можно изменить позже в настройках (`/settings`).
