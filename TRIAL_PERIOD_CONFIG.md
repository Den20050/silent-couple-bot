# Настройка периода демо режима через переменные окружения

## Описание

Период демо режима теперь настраивается через переменную окружения `TRIAL_PERIOD_DAYS` в файле `.env`.

## Использование

### В файле `.env`

Добавьте или измените переменную:

```env
# Период демо режима (дни)
# Продолжительность пробного периода для новых пар
# По умолчанию: 7 дней
TRIAL_PERIOD_DAYS=7
```

### Ограничения

- Минимальное значение: **1 день**
- Максимальное значение: **365 дней**
- По умолчанию: **7 дней** (если не указано)

### Примеры

```env
# Короткий демо период (3 дня)
TRIAL_PERIOD_DAYS=3

# Стандартный демо период (7 дней)
TRIAL_PERIOD_DAYS=7

# Расширенный демо период (14 дней)
TRIAL_PERIOD_DAYS=14

# Длинный демо период (30 дней)
TRIAL_PERIOD_DAYS=30
```

## Технические детали

### Изменения в коде

1. **`src/core/config.py`**:
   - Добавлено поле `trial_period_days` в класс `Settings`
   - Валидация: от 1 до 365 дней
   - Значение по умолчанию: 7 дней

2. **`src/core/constants.py`**:
   - `TRIAL_PERIOD_DAYS` теперь берется из `settings.trial_period_days`
   - Обратная совместимость сохранена (все места, где используется `TRIAL_PERIOD_DAYS`, продолжают работать)

3. **`env.example`**:
   - Добавлена переменная `TRIAL_PERIOD_DAYS=7` с комментариями

### Где используется

`TRIAL_PERIOD_DAYS` используется в следующих местах:

- `src/bot/handlers/start.py` - создание подписки при создании пары
- `src/bot/handlers/menu.py` - отображение информации о подписке
- `src/bot/handlers/subscription.py` - расчет оставшихся дней демо

### Важно

- Изменение `TRIAL_PERIOD_DAYS` влияет только на **новые пары**
- Существующие пары сохраняют свой период демо, установленный при создании
- После изменения переменной нужно **перезапустить бота** для применения изменений

## Проверка

Чтобы проверить, что значение применяется корректно:

1. Установите `TRIAL_PERIOD_DAYS` в `.env`
2. Перезапустите бота
3. Создайте новую пару
4. Проверьте дату окончания демо в базе данных или через команду `/subscription`
