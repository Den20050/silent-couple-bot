# Подробная инструкция по загрузке картинок

## Что делает скрипт загрузки?

Скрипт `load_images.py` выполняет следующие действия:

1. **Читает картинки** из папок `image/morning/` и `image/evening/`
2. **Загружает каждую картинку** в Telegram через Bot API (отправляет боту)
3. **Получает `file_id`** - уникальный идентификатор картинки в Telegram
4. **Сохраняет `file_id`** в базу данных (таблица `pics_pool`)

После этого бот может использовать сохраненные `file_id` для быстрой отправки картинок пользователям без повторной загрузки файлов.

## Пошаговая инструкция

### Шаг 0: Очистка старых file_id (если картинки были загружены с другого бота)

**Важно**: Если вы изменили токен бота, старые `file_id` не будут работать с новым ботом. 
В этом случае нужно очистить старые записи из базы данных перед загрузкой новых картинок.

```bash
# Очистить все картинки
python scripts/clear_images.py

# Или очистить только утренние
python scripts/clear_images.py morning

# Или очистить только вечерние
python scripts/clear_images.py evening
```

Скрипт покажет количество записей, которые будут удалены, и попросит подтверждение.

### Шаг 1: Получите ваш Telegram chat_id

Вам нужно узнать ваш Telegram chat_id, чтобы скрипт мог отправлять картинки боту для получения `file_id`.

**Вариант 1: Через бота @userinfobot**
1. Откройте Telegram
2. Найдите бота `@userinfobot`
3. Отправьте ему любое сообщение
4. Бот ответит с вашим `id` (например: `123456789`)

**Вариант 2: Через ваш бот**
1. Убедитесь, что ваш бот запущен (`python -m src.bot.main`)
2. Найдите вашего бота в Telegram
3. Отправьте команду `/start`
4. В логах бота вы увидите ваш `chat_id` (или используйте @userinfobot)

**Вариант 3: Через веб-версию Telegram**
1. Откройте https://web.telegram.org
2. Откройте консоль разработчика (F12)
3. В консоли выполните: `window.Telegram.WebApp.initDataUnsafe.user.id`
4. Вы увидите ваш `id`

### Шаг 2: Убедитесь, что бот может отправлять вам сообщения

**Важно**: Бот должен иметь возможность отправлять вам сообщения!

1. Найдите вашего бота в Telegram
2. Нажмите "Начать" или отправьте `/start`
3. Убедитесь, что бот может вам писать

Если бот не может отправлять сообщения:
- Проверьте, что бот запущен
- Убедитесь, что используете правильный токен в `.env`
- Проверьте, что бот не заблокирован

### Шаг 3: Проверьте наличие картинок

Убедитесь, что картинки находятся в правильных папках:

```bash
# Проверьте количество картинок
dir image\morning\*.jpg
dir image\evening\*.jpg

# Должно быть примерно:
# - morning: ~1104 файлов
# - evening: ~645 файлов
```

### Шаг 4: Запустите скрипт загрузки

```bash
# Замените <your_telegram_chat_id> на ваш реальный ID
python scripts/load_images.py <your_telegram_chat_id>

# Пример:
python scripts/load_images.py 123456789
```

### Шаг 5: Что происходит во время загрузки

Скрипт будет:

1. **Подключаться к базе данных** - проверка подключения
2. **Подключаться к Telegram Bot API** - инициализация бота
3. **Обрабатывать каждую картинку**:
   - Читает файл из папки
   - Отправляет боту (картинка появится в вашем Saved Messages)
   - Получает `file_id` от Telegram
   - Сохраняет в БД
   - Показывает прогресс каждые 10 картинок

4. **Выводит статистику**:
   ```
   Images loaded:
     morning: 1104
     evening: 645
     total: 1749
   ```

### Шаг 6: Проверка результата

После завершения загрузки проверьте результат:

```bash
# Проверьте количество загруженных картинок в БД
python scripts/check_tables.py

# Или через psql:
psql -h localhost -p 5433 -U bot_user -d silent_couple_bot
SELECT type, COUNT(*) FROM pics_pool GROUP BY type;
```

Должно быть:
- `morning`: ~1104 записей
- `evening`: ~645 записей

## Важные замечания

### Время выполнения

- **Скорость**: ~0.2 картинки в секунду (задержка 5 секунд между загрузками для безопасности)
- **Общее время**: ~40-60 минут для ~1700 картинок
- **Прогресс**: Скрипт показывает прогресс каждые 10 картинок
- **Задержка**: Автоматически увеличивается при обнаружении ограничений Telegram API

### Что делать с сообщениями в Saved Messages

После загрузки в вашем **Saved Messages** (Избранное) будет много сообщений с картинками. Вы можете:

- **Удалить их все** - это не повлияет на работу бота (file_id сохранены в БД)
- **Оставить** - они не мешают, но занимают место

### Если скрипт прервался

Если скрипт остановился (ошибка, прерывание):

1. **Не переживайте** - уже загруженные картинки сохранены в БД
2. **Запустите скрипт снова** - он пропустит уже загруженные картинки (проверка по `file_id`)
3. **Продолжит с места остановки** - загрузит только оставшиеся

### Ошибки и их решение

**Ошибка: "Bot token not found"**
- Проверьте `.env` файл
- Убедитесь, что `TG_BOT_TOKEN` заполнен

**Ошибка: "Connection failed"**
- Проверьте подключение к БД: `python scripts/check_db.py`
- Убедитесь, что PostgreSQL запущен

**Ошибка: "Telegram API error"**
- Проверьте токен бота
- Убедитесь, что бот не заблокирован
- Проверьте интернет-соединение

**Ошибка: "Permission denied"**
- Убедитесь, что бот может отправлять вам сообщения
- Начните диалог с ботом командой `/start`

```bash
# 3. Начните диалог с ботом в Telegram

```

## Альтернативный способ (если не хотите ждать)

Если у вас много картинок и вы не хотите ждать полной загрузки, можно:

1. **Загрузить только часть картинок** - измените скрипт, чтобы он обрабатывал только первые N файлов
2. **Загружать по мере необходимости** - измените логику бота, чтобы он загружал картинки при первом использовании

Но **рекомендуется загрузить все сразу** для максимальной производительности.
