ТЕХНИЧЕСКОЕ ЗАДАНИЕ  
Разработка Telegram-бота «Silent Couple Bot 2.0»  
(мультиязычный, оплата Stars, генерация уникальных пожеланий LLM)

----------------------------------------------------------------
1. ЦЕЛЬ ПРОЕКТА
Создать мультиязычного Telegram-бота для пар, который:
- ежедневно обменивается пожеланиями «Доброе утро» и «Спокойной ночи»;
- принимает оплату ТОЛЬКО Telegram Stars (XTR);
- генерирует уникальные пожелания на языке получателя с помощью LLM;
- полностью локализован под 15 языков;
- не выводит пользователя из Telegram для покупки звёзд.

----------------------------------------------------------------
2. ОСНОВНЫЕ ИЗМЕНЕНИЯ ОТНОСИТЕЛЬНО ОРИГИНАЛА
- Оплата: только Stars, встроенный flow покупки звёзд.
- Языки: 15 шт (ru, en, es, de, fr, it, pt, pl, uk, tr, ar, hi, kk, tg, ms).
- Картинки: без текста на изображении; текст в подписи под картинкой.
- Подписи: «Доброе утро! {ник} {пожелание LLM}» и аналогично для вечера.
- Пожелания: уникальные каждый день, на языке получателя, кэшируются 6 ч.
- Fallback: если LLM не ответил за 3 с – использовать заготовленные фразы.

----------------------------------------------------------------
3. ТЕХНОЛОГИИ
- Python 3.11, aiogram 3.x, PostgreSQL 15, Redis, arq, Alembic.
- LLM: OpenAI / Claude / локальная модель – через async API.
- Файлы: MinIO или Telegram file_id.
- Контейнеризация: Docker, docker-compose.
- CI/CD: GitHub Actions (по желанию заказчика).

----------------------------------------------------------------
4. ПОДДЕРЖИВАЕМЫЕ ЯЗЫКИ (15)
ru, en, es, de, fr, it, pt, pl, uk, tr, ar, hi, kk, tg, ms

----------------------------------------------------------------
5. КОМАНДЫ ПОЛЬЗОВАТЕЛЯ
/start          – онбординг, выбор языка, создание пары
/create_pair    – новая пара
/subscription   – статус подписки
/pay            – выбор тарифа → покупка Stars → оплата
/settings       – язык, часовой пояс, никнейм
/delete         – GDPR-удаление
/help, /share, /feedback – стандартные

----------------------------------------------------------------
6. ОПЛАТА ТОЛЬКО STARS
6.1 Тарифы (Stars)
1 месяц     – 179
3 месяца    – 480
6 месяцев   – 860
1 год       – 1400
Навсегда    – 2999

6.2 Flow
- Кнопка «Оплатить» → выбор тарифа.
- Кнопка «Купить Stars» – inline-ссылка на @PremiumBot / @ShopBot.
- После пополнения – sendInvoice(XTR) → successful_payment → подписка active.

----------------------------------------------------------------
7. ГЕНЕРАЦИЯ ПОЖЕЛАНИЙ LLM
- Триггер: отправка картинки получателю.
- Язык: locale получателя.
- Промпт: «Сгенерируй короткое (≤120 симв) свежее пожелание для {утро/вечер} на {язык}».
- Seed: {pair_id}:{day}:{type} – уникальность внутри дня.
- Кэш: Redis, TTL 6 ч, ключ wish:{pair_id}:{day}:{locale}:{type}.
- Fallback: если таймаут LLM – взять фразу из i18n.fallback_wish.

----------------------------------------------------------------
8. ЕЖЕДНЕВНЫЙ ОБМЕН
- Утро: 07:00-08:00 UTC (локальное время)
- Вечер: 21:00-22:00 UTC
- Окно: общее для пары, владелец – кто первый установил.
- Картинка: случайная из pics_pool (morning / evening).
- Подпись: «Доброе утро! {nickname} {wish}» и аналогично для вечера.
- Сохранение: daily_state.morning_caption, evening_caption.

----------------------------------------------------------------
9. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
- Время ответа ≤1 с (без LLM).
- Таймаут LLM 3 с.
- Точность напоминаний ±5 мин.
- Поддержка 10 000 активных пар без просадки.
- Полное удаление данных по GDPR за 1 запрос.

12. КРИТЕРИИ ПРИЁМКИ
1. Пользователь может сменить язык и получить все тексты на нём.
2. Оплата только Stars, flow не выводит из Telegram.
3. Подписи под картинками на языке получателя, каждый день новые.
4. LLM не повторяет фразы внутри 7 дней для одной пары.
5. Все 15 языков покрыты переводами и fallback-фразами.
6. Админ может выдать подписку и сбросить демо.
7. /delete удаляет всё за 1 запрос.
