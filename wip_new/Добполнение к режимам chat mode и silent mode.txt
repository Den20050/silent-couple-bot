2. Цель одной строкой
Дать паре один раз выбрать:
➜ «Получать пожелания в чате с ботом» (bot_dm)
➜ «Получать пожелания в нашем личном чате» (pair_dm)
Если выбран pair_dm:
бот один раз получает chat_id их диалога и больше все картинки шлёт туда;
кнопка «Отправить в ответ» остаётся только в личке с ботом;
бот никогда не сохраняет текст сообщений пары.

Python
Copy
class Pair(Base):

Если нажали pair_dm → сразу шлём обоим в их личный чат короткое сообщение-якорь:
Copy
Нажмите ▶️, чтобы пожелания приходили сюда
[▶️ Подключить чат]  →  callback: `anchor_pair_chat`
callback приходит из их личного чата → ловим message.chat.id → сохраняем в pair.private_chat_id
сразу удаляем это сообщение (deleteMessage)
редактируем кнопку у второго пользователя на «✅ Чат подключён»
5. Логика отправки картинок
В morning_sender.py / evening_sender.py замени строку:
Python
Copy
# старый вариант
await bot.send_photo(chat_id=recipient.id, ...)

# новый вариант
target_chat = (
    pair.private_chat_id
    if pair.delivery_chat == DeliveryChat.PAIR_DM and pair.private_chat_id
    else recipient.id
)
await bot.send_photo(chat_id=target_chat, ...)
Подпись к картинке для pair_dm добавляем имя отправителя:
Python
Copy
if pair.delivery_chat == DeliveryChat.PAIR_DM:
    caption += f"\n— от {sender.first_name}"
Кнопка «Отправить в ответ» не прикрепляется к сообщению в pair_dm — она остаётся в чате с ботом.
6. Обработка callback «Отправить в ответ»
Ничего не меняется: callback приходит из лички с ботом, бот шлёт ответную картинку туда же, куда пришла первая:
Python
Copy
# внутри `send_response()`
target_chat = (
    pair.private_chat_id
    if pair.delivery_chat == DeliveryChat.PAIR_DM and pair.private_chat_id
    else initiator.id
)
await bot.send_photo(chat_id=target_chat, ...)

8. Privacy & GDPR
Добавь в PRIVACY.md:
Если вы выберете «В нашем личном чате», бот один раз пришлёт туда картинку и не сохраняет текст сообщений участников. Бот видит только свои собственные сообщения.
9. Что не делаем
Не добавляем бота в участники чата
Не парсим чужие сообщения
Не делаем админ-прав
Не храним историю переписки
