# Решение конфликта экземпляров бота

## Проблема

Ошибка:
```
Failed to fetch updates - TelegramConflictError: Telegram server says - Conflict: terminated by other getUpdates request; make sure that only one bot instance is running
```

**Причина:** Запущено несколько экземпляров бота одновременно. Telegram API позволяет только **один** экземпляр бота использовать polling для одного токена.

## Быстрое решение

### Шаг 1: Остановить все локальные экземпляры

**Windows PowerShell:**
```powershell
# Найти все процессы Python, запущенные с ботом
Get-Process python | Where-Object {$_.Path -like "*Silent-Couple-Bot*"}

# Остановить все процессы Python (ОСТОРОЖНО - остановит ВСЕ Python процессы!)
taskkill /f /im python.exe

# Или более безопасно - найти и остановить конкретные процессы
Get-Process python | Where-Object {$_.CommandLine -like "*run.py*"} | Stop-Process -Force
```

**Или вручную:**
- Нажмите `Ctrl+C` во всех терминалах, где запущен бот
- Закройте все окна терминала с ботом

### Шаг 2: Проверить, не запущен ли бот на сервере

Если бот должен работать на сервере через webhook, убедитесь, что он запущен там:

```bash
ssh root@91.222.237.94
sudo systemctl status silent-couple-bot-webhook
```

**Если бот запущен на сервере:**
- НЕ запускайте бот локально в polling режиме
- Используйте только webhook на сервере для production

**Если бот НЕ должен быть на сервере:**
- Остановите его на сервере:
```bash
ssh root@91.222.237.94
sudo systemctl stop silent-couple-bot-webhook
```

### Шаг 3: Проверить webhook в Telegram

Если бот был запущен на сервере с webhook, нужно удалить webhook перед запуском локально:

```bash
# На сервере или локально (если есть доступ к токену)
curl -X POST "https://api.telegram.org/bot${TG_BOT_TOKEN}/deleteWebhook"
```

Или используйте скрипт:
```bash
python scripts/set_webhook.py delete
```

### Шаг 4: Запустить только один экземпляр локально

После того как все остановлено:

```bash
python run.py
```

**Важно:** Запускайте только **один** экземпляр!

## Проверка перед запуском

### Проверить запущенные процессы Python

**Windows:**
```powershell
Get-Process python | Format-Table Id,ProcessName,Path
```

**Linux/Mac:**
```bash
ps aux | grep python | grep -v grep
```

### Проверить webhook статус

```bash
curl "https://api.telegram.org/bot${TG_BOT_TOKEN}/getWebhookInfo"
```

Если `url` не пустой - webhook установлен, нужно удалить перед polling.

## Правила работы

### Для разработки (локально)

✅ **Можно:**
- Запустить `python run.py` локально (polling режим)
- Бот работает только на вашем ПК

❌ **Нельзя:**
- Запускать бот одновременно локально И на сервере
- Запускать несколько экземпляров локально

### Для production (на сервере)

✅ **Можно:**
- Запустить webhook на сервере через systemd
- Бот работает только на сервере

❌ **Нельзя:**
- Запускать бот локально, если он уже на сервере
- Использовать polling на сервере (только webhook)

## Автоматическая проверка (опционально)

Можно добавить проверку в код, чтобы предотвратить запуск нескольких экземпляров. Но проще просто следить за этим вручную.

## Частые ошибки

### Ошибка 1: Забыл остановить предыдущий запуск

**Решение:** Всегда проверяйте процессы перед запуском:
```powershell
Get-Process python
```

### Ошибка 2: Бот запущен на сервере, но пытаюсь запустить локально

**Решение:** 
1. Остановите на сервере: `sudo systemctl stop silent-couple-bot-webhook`
2. Или удалите webhook и запускайте локально

### Ошибка 3: Несколько терминалов с ботом

**Решение:** Закройте все терминалы, оставьте только один.

## Проверка после исправления

После остановки всех экземпляров и запуска одного:

1. ✅ Логи должны показывать успешный запуск polling
2. ✅ Нет ошибок `TelegramConflictError`
3. ✅ Бот отвечает на команды в Telegram

Если ошибка повторяется - проверьте еще раз все процессы и webhook статус.
